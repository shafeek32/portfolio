## 🌌 Overview

**SHAFEEK OS** is a handcrafted **Pixel-Art Retro Desktop Operating System** and software engineering portfolio. Inspired by late 90s / early 2000s desktop OS interfaces, it features free-floating draggable windows, a twilight city pixel art workstation background, an interactive MS-DOS CLI terminal, classic retro mini-games (Minesweeper & Snake), and a zero-dependency Web Audio synthesizer.

## ✨ Key System Features

### 🪟 1. Free-Floating Multi-Window OS
* **True Desktop Window Manager**: Move, drag, focus, minimize, maximize, and stack windows over each other.
* **Smart Z-Index Elevation**: Clicking or dragging any window brings it to the top layer.
* **100% Fixed Viewport**: Zero unwanted browser scrollbars — authentic desktop feel with internal window scroll containers.

### 🎨 2. Handcrafted Pixel-Art Asset System
* **Twilight Skyline Workstation**: Custom 16/32-bit pixel art wallpaper with CRT monitor desk, balcony palm trees, glowing purple twilight clouds, and lit skyscrapers.
* **Pixel Character Portrait**: 32-bit pixel-art avatar of Shafeek in a navy hoodie.
* **Custom SVG Icon Library**: Pixel-perfect vector icons for all applications, folders, tools, and system components.

### 🎮 3. Classic Retro Games
* **💣 `Minesweeper.exe`**: Authentic 9x9 grid with 10 mines, 3-digit LCD counters, interactive smiley status button (`🙂` `😵` `😎`), and flag mode.
* **🐍 `Snake_1997.exe`**: Classic arcade snake game with arrow/WASD controls, mobile on-screen D-Pad, score tracking, and persistent high scores.

### 💻 4. Interactive MS-DOS Terminal (`C:\COMMAND.COM`)
* **Working CLI Commands**: `help`, `about`, `projects`, `skills`, `journey`, `resume`, `contact`, `date`, `whoami`, and `clear`.
* **Command History**: Navigate previous commands using Up/Down arrow keys.

### 🔊 5. Zero-Dependency Web Audio Synthesizer
* **Retro Sound Effects**: Real-time sound synthesis for window open/close chimes, mechanical clicks, and game blips.
* **One-Click Mute**: Instant audio toggle via the top system bar and control panel.

### 📄 6. ATS-Ready Resume Viewer (`Resume.pdf`)
* **Dual Format**: Interactive in-window viewer with one-click official PDF download and automated ATS-optimized print stylesheet (`Ctrl+P`).

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/shafeek32/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
> System boots at **`http://localhost:3000/`**

### 4. Build for production
```bash
npm run build
```
